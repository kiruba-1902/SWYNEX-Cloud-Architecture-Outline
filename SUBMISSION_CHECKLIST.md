# Before submitting

1. Create a public GitHub repository named `SWYNEX-Cloud-Architecture-Outline`.
2. Upload `README.md` and `architecture.mmd` (or upload the whole folder).
3. Open the repository in a private/incognito browser window and confirm the README is visible without signing in.
4. Publish the text in `linkedin_post.txt` on LinkedIn.
5. Mention `@SWYNEX Technologies`, select the official company page, and attach a screenshot of your architecture diagram or repository.
6. Copy the public GitHub repository URL into the Task submission link field.
7. Copy the LinkedIn post URL into the LinkedIn explanation post link field.
8. Test both links in a private/incognito window before submitting.

Important: This is a conceptual document. Do not say that you deployed AWS resources unless you actually did so.
